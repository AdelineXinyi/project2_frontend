# Project 2 Frontend

Vue.js frontend for the SciSciNet LLM data analysis system.

Features:
- Chat interface
- Vega-Lite interactive dashboards
- Filtering and hovering interactions
- Real-time visualization rendering

## Run

```bash
python -m http.server 3000
```

Open:
http://localhost:3000

Backend should run on:
http://localhost:8000
